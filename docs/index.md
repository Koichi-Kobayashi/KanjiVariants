# KanjiVariants

MJ縮退マップに基づく漢字代替候補の検索・置換と、公的な漢字・音訓情報を参照する .NET 6 ライブラリです。通常の実行ではExcelやネットワーク接続を必要としません。

## 主な機能

- MJ縮退マップに基づく異体字・代替文字の検索と置換
- JIS X 0208 / JIS X 0213への所属判定
- 常用漢字・音訓・旧字体等の参照
- 教育漢字と小学校の配当学年
- 人名用漢字と名前に使用可能な漢字の判定
- 常用漢字の音訓別学校段階・付表語
- 表外読みの判定
- 送り仮名の公式掲載語の参照
- MJ文字図形名・Unicode・IVS/SVSなどの文字情報検索

## 主なデータソース

MJ文字情報一覧表 Ver.006.02・MJ縮退マップ Ver.1.2.0、Unicode IVD 2026-08-03・Standardized Variants 18.0.0、文化庁の常用漢字表の音訓索引・送り仮名の付け方、文部科学省の学年別漢字配当表・音訓の学校段階別割り振り表を使用しています。

文字データには出典ごとの利用条件が適用されます。リポジトリのREADMEとLICENSE-NOTICES.mdで出典・加工内容・利用条件を確認してください。
